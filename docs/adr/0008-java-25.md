# 0008 — Java 25 (LTS) no lugar do Java 21

**Status:** aceita (06/11/2026) · altera em parte a 0002 (a versão do Java)

## Contexto

O back usa threads virtuais (`spring.threads.virtual.enabled: true`): cada requisição roda numa thread virtual, e poucas threads de base (uma por núcleo) carregam todas elas. No Java 21, uma thread virtual que espera dentro de um bloco `synchronized` **prende** a thread de base (*pinning*).

O teste de carga da Etapa 15 travou o back por inteiro. O retrato das threads mostrou as 12 threads de base presas no `ConcurrentHashMap.computeIfAbsent` (um `synchronized`) do `ExceptionHandlerExceptionResolver` do Spring, esperando uma thread virtual que segurava uma trava (`ReentrantLock`) do cache de anotações do Spring. Essa thread, por sua vez, não tinha thread de base livre para continuar: um impasse. Acontece quando muitas conexões caem juntas com os caches internos do Spring ainda frios, como um salão cheio de celulares entrando e saindo do Wi-Fi. O resultado é o sistema parado para todos os restaurantes até alguém reiniciar o servidor.

O Java 24 resolveu isso (JEP 491: o `synchronized` não prende mais a thread de base). O Java 25 é a versão de suporte longo (LTS) que já traz a correção.

## Decisão

- O back passa para o **Java 25** (Temurin): o `pom.xml` (`java.version`), a imagem Docker do Fly.io (`eclipse-temurin:25`) e o CI.
- As threads virtuais continuam ligadas.

Alternativas descartadas:

- **Desligar as threads virtuais no Java 21:** funciona (o Tomcat volta às suas 200 threads normais, e o teste de carga passou assim), mas abre mão das threads virtuais e deixa a troca de versão para depois, com o mesmo trabalho.
- **Aumentar o número de threads de base:** só adia o impasse.

## Consequências

- Quem desenvolve precisa do JDK 25 (ver README).
- O Java 25 tem suporte longo da Temurin; o 21 continuaria com suporte, mas sem a correção do *pinning*.
- Ainda prendem a thread de base no Java 25 as chamadas nativas e a inicialização de classes; o código do projeto não faz espera nesses pontos.
